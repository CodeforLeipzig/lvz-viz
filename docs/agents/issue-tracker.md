# Issue tracker: GitHub

Issues live in GitHub Issues on `CodeforLeipzig/lvz-viz`.
Clones of forks often have several remotes, so always pass `-R CodeforLeipzig/lvz-viz` to `gh issue`, and use `repos/CodeforLeipzig/lvz-viz/...` for `gh api`.

**PRs as a request surface: no.** _(Set to `yes` if this repo treats external PRs as feature requests; `/triage` reads this flag.)_
